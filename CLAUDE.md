# Working in this repository

## Branch names

Name every branch after what it does, with a type prefix and a slash. Never start a branch name
with `claude/` or use a generated name.

| Prefix | Use for | Example |
| --- | --- | --- |
| `fix/` | A bug fix | `fix/czech-email-subject-encoding` |
| `improve/` | An improvement to something that already works | `improve/approval-queue-loading` |
| `feature/` | Something new | `feature/weekly-client-summary` |
| `docs/` | Documentation only | `docs/sandbox-test-plan` |

After the prefix: lowercase words joined by hyphens, short and specific.
